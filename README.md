## 🎮 About the Game

Shelve the Potions! is a first-person casual puzzle and simulation game developed and published by Knight Owl Games. It released for Windows on August 24, 2026. Players restore order to an enchanted workshop by organizing more than 2,000 potions across handcrafted shelves, deciphering clues, and solving unique sorting rules.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Shelve the Potions!**. This trainer enhances the game's potion-organizing loop by improving movement, carrying capacity, pickup speed, hint access, and puzzle assistance. It is designed for the single-player Windows version and does not add combat features because Shelve the Potions! has no combat system.

**Target Audience:** Players who want a more relaxed way to explore the workshop, collect potions, find clues, use assistance abilities, and complete the game's sorting puzzles without repetitive travel or cooldown delays.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Start the game and load your save before activating movement options. Enable Increased Movement Speed when traveling between shelves, clue stations, and potion locations. Disable it if movement becomes too fast for precise interactions.

### Tools & Inventory

Enable Unlimited Carry Capacity before collecting large groups of bottles. This reduces trips between loose potion locations and their matching shelves while preserving the normal sorting and placement objectives.

### World & Environment

Use Highlight Missing Potions to locate bottles that are difficult to spot in the workshop. No Ability Cooldown is useful when relying on cat assistance, clue highlighting, or the assemble ability during a difficult puzzle.

### Combat & Weapons

Shelve the Potions! does not include combat, enemies, health, or combat resources. The trainer therefore provides no combat enhancements and focuses entirely on exploration, inventory handling, hints, and potion-sorting puzzles.
